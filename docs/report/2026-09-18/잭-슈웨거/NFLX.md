# 잭 슈웨거 — 마켓 위저드

## 한 줄 결론
Netflix는 펀더멘털과 기술적 신호가 엇갈리는 전형적 딜레마 상황이다. fundamentals는 견고하나(-40% 하락 후 매력적 밸류에이션), 기술적 추세는 하락세다. 마켓 위저드라면 "진입 전에 손절 지점을 정하고, 추세가 확인될 때까지 기다리라"고 조언할 것이다.

## 내 철학에서 본 이 기업

내가 인터뷰한 거의 모든 트레이더가 한 가지를 강조했다 — **리스크 관리가 수익 창출보다 우선한다**. 폴 튜더 존스는 항상 "얼마를 벌 수 있는가"보다 "얼마를 잃을 수 있는가"를 먼저 생각한다고 했다.

Netflix를 이 잣대로 평가하겠다.

**시장 전체의 방향 (오닐의 M)**:
S&P 500은 어떻게 움직이고 있는가? 2026년 시장은 혼조세 — 인플레이션 우려 vs 금리 인하 기대. Netflix는 베타 1.59로 시장보다 변동성이 크다. 시장이 하락세면 Netflix는 더 크게 떨어질 수 있다.

**추세 확인**:
- 52주 고점 $126.71 → 현재 $75.31 (-40%)
- 52주 최저 $65.08 — 현재가에서 -14% 하락 가능
- **추세는 명백히 하락세다**

마이클 마커스라면 이렇게 물었을 것이다 — "추세를 거스르는 포지션이라면 그만한 근거가 있는가?"

**펀더멘털과 기술적 신호의 정렬**:
- 펀더멘털: 강함 (매출 +19.2% YoY, 영업이익률 29.5%, ROE 49.54%)
- 기술적: 약함 (하락 추세, 52주 고점 대비 -40%)
- **서로 다른 방향을 가리키고 있다**

마커스의 원칙: "둘 다 같은 방향을 가리킬 때 가장 큰 확신을 가졌다." 현재 Netflix는 같은 방향이 아니다.

## 체크리스트 평가

| 항목 | 평가 | 근거 |
|------|------|------|
| 시장 전체 방향 | △ | 혼조세, Netflix 베타 1.59로 변동성 큼 |
| 추세 확인 | ✕ | 명백한 하락 추세 — 추세를 거스르는 진입 |
| 펀더멘털-기술 정렬 | ✕ | 펀더멘털 강함, 기술적 약함 — 엇갈림 |
| 손절 지점 | ○ | 매수가 대비 7-8% 하락 시 손절 가능 |
| 최대 손실 | △ | -40% 하락이 이미 있음, 추가 하락 시 손실 폭 큼 |
| 여러 시나리오 | △ | 회복 시나리오 vs 추가 하락 시나리오 존재 |
| 판단의 성격 | △ | Ackman 매수에 영향받을 수 있음 — 감정적 요소 경계 |

## 밸류에이션 판단

슈웨거는 밸류에이션에 큰 비중을 두지 않는다. 그보다는 **손익비**와 **손절 관리**에 집중한다.

**손익비 분석**:
- 매수 시나리오(회복): $75 → $95-110 = +26-46%
- 손실 시나리오(추가 하락): $75 → $55-60 = -20-27%
- **손익비: 약 1:1.5** — 매력적이지 않다

마켓 위저드들의 기준으로는 손익비가 1:3 이상일 때만 매력적인 거래로 본다. 현재 Netflix의 손익비는 1:1.5에 불과하다.

**손절 지점**:
- 데니스 원칙: 진입 후 추세가 꺾이면 즉시 빠져나온다
- 오닐 원칙: 매수가 대비 7-8% 하락 시 예외 없이 손절
- 현재 $75에서 매수 시 손절 라인: **$69-70**

**기다림의 포지션**:
와인스타인처럼 "여러 조건이 정렬될 때까지 기다려야 한다." 현재 Netflix에서 정렬되지 않은 조건:
1. 추세 전환 확인 (하락 추세 → 횡보 또는 상승 추세)
2. 거래량 증가와 함께의 바닥 다지기
3. Engagement 하락 우려 해소

## 핵심 리스크

1. **추세 리스크**: 하락 추세에서의 매수는 "싸다"는 이유만으로 잡는 것과 같다
2. **변동성 리스크**: 베타 1.59 — 시장 대비 1.6배 변동, 손절 관리 어려움
3. **추격 매수 리스크**: Ackman 매수에 편승할 수 있다 — "놓친 기회에 대한 아쉬움"은 감정이다
4. **포지션 크기 리스크**: -40% 하락 후 "더 싸졌다"며 포지션을 키우면 안 된다

## 최종 의견 및 조언

**의견: 관망 (추세 확인 대기)** | **확신도: 5/10**

"시장에서 돈을 버는 방법은 수없이 많지만, 돈을 잃는 이유는 놀라울 만큼 비슷하다."

내가 인터뷰한 트레이더들은 하나같이 이런 조언을 했다:
- **마커스**: "포지션이 불리하게 움직이면 빠르게 인정하고 빠져나와야 한다. 희망은 전략이 아니다."
- **튜더 존스**: "'얼마를 벌 수 있는가'보다 '얼마를 잃을 수 있는가'를 먼저 생각한다."
- **세이코타**: "손실을 인정하고 빠져나오는 것을 감정적 결정이 아니라 기계적 규칙으로 만들어야 한다."

현재 Netflix에서 매수를 고려한다면:
1. **반드시 손절 라인을 정하라**: $69-70 (매수가 대비 7-8%)
2. **포지션 크기를 작게**: 전체 자산의 1-2% 이내
3. **추세가 확인될 때까지 기다려라**: 하락 추세가 멈추고 횡보 또는 상승 추세로 전환될 때까지

"자존심보다 자본이 중요하다." 현재 Netflix는 매력적이나, 추세가 좋지 않다. 기다리는 것도 유효한 포지션이다.

"시장은 끊임없이 수업료를 청구한다." 지금 Netflix에서 무리하게 매수하는 것은 수업료를 내는 것과 같다.

# 애스워스 다모다란의 TSM 가치평가 보고서

**인물: 애스워스 다모다란 | 의견: 매수 | 확신도: 7/10**

## 핵심 논거:
- 2025년 FCF $32.3B(실제 보고서 기준)에서 2026년 매출 성장률 30% 적용 시, 5년간 FCF CAGR 약 20%로 추정되어 강력한 현금 창출 능력 지속
- 현재 PER 20.3배는 고성장 반도체 기업 치고는 합리적이며, DCF 기반 내재가치 $988.9B(주당 약 $381) 대비 시가총액 $1.12조는 약간 고평가이나 성장 프리미엄 고려 시 매력적
- AI/HPC 수요 폭증으로 TSM의 첨단 공정(N3, N2) 독점적 지위가 향후 5년간 현금흐름 성장의 핵심 동력

## 적정가/매수 가격대:

- 기본 시나리오: $381 (주당)
- 비관 시나리오: $320 (주당)
- **매수 가격대: $380 이하**

## 트리거·재검토 조건:
- 2nm 공정 양산 수율 및 마진 영향 모니터링 (2026년 하반기)
- 해외 팹(미국, 일본) 가동에 따른 마진 희석폭 변화

## 대표 발언:
"가치평가에서 대략적으로 맞는 것이 정확하게 틀리는 것보다 낫다. TSM의 사례에서 우리는 핵심에 집중해야 한다: AI 시대의 반도체 수요라는 거대한 파도 위에 올라타 있는가?"

## 1. 스토리 수립: TSM의 전략적 포지셔닝

### 비즈니스 스토리
TSM는 세계 유일의 첨단 로직 반도체 파운드리입니다. AI 시대의 핵심 인프라인 GPU, AI 가속기, 고성능 컴퓨팅(HPC) 칩의 **90% 이상**을 독점 생산합니다. 이는 단순한 제조업체가 아니라, **반도체 생태계의 유틸리티**와 같은 존재입니다.

**전략적 우위:**
1. **기술 독점**: 3nm, 2nm 등 첨단 공정에서 2~3년 앞선 기술력
2. **규모의 경제**: 연간 CAPEX $40-50B 투자로 진입장벽 극대화
3. **생태계 의존성**: Apple, NVIDIA, AMD 등 고객사가 TSM 없이는 제품 출시 불가
4. **지정학적 프리미엄**: 대만 해협 리스크에도 불구하고 대체 불가능한 위치

### 스토리의 핵심 가정
- AI 수요는 향후 5년간 연평균 30% 이상 성장
- TSM는 HPC 매출 비중(58%)을 유지하며 ASP 상승 효과 누림
- 2nm 공정 양산(2025년 말~2026년)으로 추가 마진 개선
- 해외 팹 가동에 따른 마진 희석은 제한적(2~4%)

## 3. 할인율 산정 (WACC)

### WACC 구성요소
- **주식 비용(Ke)**: 10.5%
  - 무위험 이자율(Rf): 4.5% (10년 미국 국채)
  - 시장 위험 프리미엄(ERP): 6.0%
  - 베타(β): 1.0 (반도체 업종 평균)
- **부채 비용(Kd)**: 4.0% (세후)
- **자본구조**: 주식 90%, 부채 10%

### WACC 계산
```
WACC = (90% × 10.5%) + (10% × 4.0%) = 9.45% + 0.40% = 9.85% ≈ 10%
```

**할인율 10% 적용 이유:**
- 반도체 업종의 시스템적 리스크 반영
- 대만 지정학적 리스크 프리미엄(약 1%)
- 고성장 기업에 적합한 할인율

## 4. 터미널 밸류 계산

### 터미널 밸류 공식
```
Terminal Value = FCF₂₀₃₀ × (1 + g) / (WACC - g)
```
- FCF₂₀₃₀: US$79.8B
- 터미널 성장률(g): 3% (장기 GDP 성장률 + 인플레이션)
- WACC: 10%

### 계산
```
Terminal Value = $79.8B × 1.03 / (0.10 - 0.03) = $82.2B / 0.07 = US$1,174.3B
```

## 5. 내재가치 산출 (2단계 DCF)

### 1단계: 명시적 예측 기간(2026-2030) FCF 현재가치
| 연도 | FCF(US$B) | 할인 팩터(10%) | 현재가치(US$B) |

| 2026 | 42.0 | 0.9091 | 38.2 |

| 2029 | 72.5 | 0.6830 | 49.5 |

### 2단계: 터미널 밸류 현재가치
```
Terminal Value PV = $1,174.3B × 0.6209 = US$728.7B
```

### 총 기업가치
```
Total Enterprise Value = $227.9B + $728.7B = US$956.6B
```

### 순현금 조정
- 2025년 기준 현금 및 유가증권: US$98B (NT$2,767.86B)
- 총 부채: 약 US$30B (추정)
- **순현금**: US$68B

### 주주가치 및 주당 가치
```
주주가치 = $956.6B + $68B = US$1,024.6B
주당 가치 = $1,024.6B / 2.6B주 = 약 US$394
```

**기본 시나리오 내재가치: US$394 (주당)**

## 8. 스토리와 숫자의 일치 여부

### 일치하는 부분
✅ **AI 수요 스토리**: HPC 매출 비중 58% → 2026년 1Q에서도 지속 성장  
✅ **기술 리더십**: 3nm 매출 비중 24%(2025) → 2nm 양산 앞섬  
✅ **현금 창출**: FCF $32.3B에서 42B로 증가 → 스토리와 부합  

### 불일치하는 부분
⚠️ **해외 팹 리스크**: 미국/일본 팹 가동에 따른 마진 희석이 시장에서 과소평가될 수 있음  
⚠️ **지정학적 리스크**: 대만 해협 리스크가 WACC에 완전히 반영되지 않았을 수 있음  

### 스토리-숫자 정합성 평가: **양호 (8/10)**
핵심 가정(AI 수요, 기술 리더십, 현금 창출)이 실제 재무 데이터와 일치하며, 리스크 요소도 합리적으로 반영됨.

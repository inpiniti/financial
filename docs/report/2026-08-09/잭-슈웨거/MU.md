# MU 투자 보고서 — 잭 슈웨거 (마켓 위저드)
> 날짜: 2026-08-09 | 투자의견: 매수 (조건부·트렌드추종) | 확신도: 6/10

## 한 줄 결론
펀더멘털(HBM 완판, Forward PER 5.66배, PEG 0.13)과 기술적 반등이 같은 방향을 가리키고 있어 마커스가 말한 "정렬" 조건은 충족되지만, 소송 리스크와 베타 2.21의 변동성 때문에 포지션은 작게, 손절은 짧게 — 승률이 아니라 손익비로 접근한다.

## 내 철학에서 본 이 기업
제가 인터뷰한 위저드들이라면 이 종목을 두 가지로 나눠서 봤을 겁니다. 첫째, "이야기"— HBM 판매완료(sold-out), Forward PER 5.66배, PEG 0.13. 이건 마이클 마커스가 좋아하는 그림입니다. 펀더멘털이 강하고 실적이 서프라이즈를 내는데(FQ3 EPS +21.3%), 주가도 저점($530, 7/13)에서 이미 +65% 반등했습니다. 둘째, "위험"— 6월 말 DRAM 가격조작 집단소송, 경영진 신인의무 위반 조사, 베타 2.21, 52주 고점 대비 -30.1% 상태에서의 반등. 폴 튜더 존스라면 이 종목에서 먼저 "내가 얼마를 잃을 수 있는가"를 물었을 겁니다. 저는 이 종목을 펀더멘털 스토리로 매수하되, 트레이더의 규율(손절·사이징)로 감싸서 접근하는 것을 권합니다.

## 밸류에이션 판단 — 트레이드 설계 (계산 과정)

저는 배수·현금흐름으로 "적정가"를 계산하지 않습니다. 대신 진입가·손절가·목표가·손익비·포지션 크기를 계산합니다.

### 1) 가격 구조 확인
| 항목 | 값 |
|---|---|
| 현재가 (2026-08-07 종가) | $877.57 |
| 최근 스윙 저점 (7/13) | $530 |
| 직전 저점 (7/27) | $823 |
| 52주 고점 (구조적 상단) | $1,255 |
| 52주 저점 | $113.46 |
| 베타 | 2.21 (변동성 매우 큼) |

$530(7/13) → $823(7/27) → $877.57(8/7)로 저점을 높여가는 중이나, 아직 이전 고점권($1,089~$1,255)을 재돌파하지 못했습니다. 이건 "추세 재개 후보"이지 "확인된 신고가 돌파"는 아닙니다. 따라서 두 가지 진입 시나리오로 나눕니다.

### 2) 진입가

**시나리오 A (보수적, 권장) — 돌파 확인 후 진입**
- 진입 트리거: $900 종가 돌파 (심리적 저항 + 직전 조정 국면 상단권 상회 확인)
- 이유: 마크 와인스타인 식 "조건이 정렬될 때까지 기다린다" — 현재가는 아직 저항대 내부에 있어 성급한 진입은 회피

**시나리오 B (공격적) — 현재가 즉시 진입**
- 진입가: $877.57 (2026-08-07 종가)
- 이유: 펀더멘털·기술적 정렬이 이미 확인됐고, FQ4 실적(9/23)까지 시간 여유가 있어 선진입 후 손절로 리스크를 통제하는 방식

이하 계산은 실행 가능성이 높은 **시나리오 B(현재가 진입)** 기준으로 제시하되, A로 진입 시 손절/목표만 같은 비율로 평행이동하면 됩니다.

### 3) 손절가 (오닐 7~8% 규칙 적용)
```
진입가 = $877.57
손절가 = 진입가 × (1 - 0.075) = $811.75  → $810로 반올림 (직전 저점 $823 하회 확인 지점, 구조적 지지 붕괴 확인)
손실폭 = $877.57 - $810 = $67.57 (주당, -7.7%)
```
직전 저점 $823을 하회하면 "저점을 높여가던 회복 구조"가 깨진 것으로 간주 — 예외 없이 손절.

### 4) 목표가 (2단계 — 데니스식 "이길 땐 오래 보유")
| 목표 | 가격 | 근거 |
|---|---|---|
| 1차 목표 (부분 익절) | $1,150 | 7월 랠리 고점권($1,089~$1,152) 재진입 지점 |
| 2차 목표 (구조적 상단) | $1,255 | 52주 고점, 최초 돌파 시도 지점 |
| 러너(잔여 포지션) | 트레일링 20% | 2차 목표 돌파 후에는 고정 목표 대신 최근 고점 대비 -20% 하락 시 청산하는 추적 손절로 전환 (추세가 꺾일 때까지 보유) |

### 5) 손익비 계산
```
1차 목표 기준: (1,150 - 877.57) / (877.57 - 810) = 272.43 / 67.57 = 4.03 : 1
2차 목표 기준: (1,255 - 877.57) / (877.57 - 810) = 377.43 / 67.57 = 5.59 : 1
```
승률이 40%만 되어도 4:1 손익비면 기대값은 플러스입니다. 이 종목은 승률을 걱정할 필요가 없는 구조입니다.

### 6) 포지션 사이징 (래리 하이트 1% 규칙, 가정: 계좌 $100,000)
```
허용 손실(1%) = $100,000 × 1% = $1,000
주당 손실폭 = $67.57
매수 수량 = $1,000 / $67.57 ≈ 14.8주 → 14주
포지션 금액 = 14주 × $877.57 = $12,286 (계좌의 약 12.3%)
```
2% 리스크 허용 시(공격적): 29주, $25,449(계좌의 25.4%) — 베타 2.21·소송 리스크 존재를 감안하면 **1% 규칙을 기본값**으로 권장합니다. 연승 직후 사이즈를 키우고 싶은 유혹(체크리스트 항목)은 지금 이 종목처럼 이미 반등한 종목에서 특히 경계해야 합니다.

## 리스크
- **소송 리스크(바이너리)**: DRAM 가격조작 집단소송(2026-06 제기) + 경영진 신인의무 위반 조사. 판결/화해 뉴스는 예측 불가능한 갭 리스크 — 슈웨거가 말하는 "예측 불가능한 사건"에 해당. 손절가로도 완전히 방어되지 않는 갭다운 가능성 있음(오버나잇 뉴스).
- **밸류에이션 분산**: 애널리스트 목표가가 $361~$2,200으로 극단적으로 갈림 — 시장이 이 종목의 미래를 두고 합의하지 못하고 있다는 신호, 변동성 지속 예상.
- **사이클 산업**: DRAM/NAND은 본질적으로 붐-버스트 산업. 현재의 가격 급등(가치 드라이버 #3)이 꺾이면 EPS 서프라이즈 사이클도 함께 꺾인다.
- **시장 전체 방향 미확인**: 데이터 팩에 SOX/나스닥 방향 데이터가 없어 오닐의 "시장이 먼저" 원칙을 완전히 검증하지 못했다 — 진입 전 지수 레벨을 반드시 재확인할 것.

## 최종 의견
제가 인터뷰한 트레이더 중 누구도 "이 회사가 얼마짜리인가"로 시작하지 않았습니다. 다들 "내가 틀렸을 때 어디서 나갈 것인가"로 시작했죠. MU는 펀더멘털과 기술적 반등이 같은 방향을 가리키는, 마커스가 좋아할 조합입니다. 손절 $810, 목표 $1,150~$1,255, 손익비 4~5.6:1 — 이 정도면 승률이 낮아도 살아남는 구조입니다. 하지만 소송이라는 예측 불가능한 사건이 걸려 있는 한, 포지션은 계좌의 1% 리스크로 작게 가져가십시오. "얼마를 벌 수 있는가"가 아니라 "얼마를 잃을 수 있는가"를 먼저 정하고 들어가는 것 — 그게 전부입니다.

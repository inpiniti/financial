# TSM (Taiwan Semiconductor Manufacturing Co., ADR) 공용 데이터 팩

조회일: 2026-08-09 (시세 기준일: 2026-08-07 미국 정규장 종가, Yahoo Finance) | 재무 통화: TWD(원자료) / 주가·밸류에이션: USD(ADR)
ADR 비율: 보통주 5주 : ADS 1주. 환헤지 없음(비헤지) — TWD/USD 변동이 EPS·마진에 그대로 반영.

## 1. 기업 개요
- **사업 모델**: 세계 최대 순수 파운드리(위탁생산). 첨단 로직 공정(2nm/3nm/5nm) + CoWoS 패키징 독점적 지위.
- **주요 고객/응용처**: HPC(AI 가속기), 스마트폰, IoT, 자동차, 소비자 가전. 최대 고객군은 Nvidia·Apple·AMD 등 팹리스.
- **경쟁사**: Samsung Foundry, Intel Foundry(IFS), UMC, GlobalFoundries(GFS) — 첨단 공정은 사실상 TSMC·Samsung 양강, 2nm 이하는 TSMC 사실상 독주(글로벌 첨단 파운드리 점유율 약 73%).

## 최근 뉴스 · 리스크
- **중국 수출 규제**: 4월 H20 사실상 금수(재고손상 $4.5B+매출손실 $2.5B 반영) → 젠슨 황-트럼프 회동 후 철회, 8월 초 상무부(BIS) H20/H200 라이선스 발급 시작. 25% 관세 부과 여부 등 정책 변수 지속.
- **반독점**: 2025-09-15 중국 SAMR, Mellanox 인수(2020, $6.9B) 관련 반독점법 위반 예비 판정(예의주시 필요, 후속 조치 확인 불가).
- **경쟁**: 커스텀 ASIC(구글 TPU v7, AWS Trainium3, MS Maia200, Meta MTIA) 추론 워크로드 잠식 — 2026년 커스텀 ASIC 서버 출하 +44.6%(GPU 서버 +16.1% 대비 가속).
- **소송**: AI 관련 저작권 침해 소송 다수(투자자發 파생소송 포함) 진행 중, 세부 결과 확인 불가.
- **차기 실적일**: 2026-08-26 (Q2 FY2027).

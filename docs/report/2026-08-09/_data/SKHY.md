# SKHY (SK하이닉스) 공용 데이터 팩

**조회일**: 2026-08-09
**티커 해석**: 스폰 프롬프트의 SKHY는 SK하이닉스 ADR(나스닥 예정 티커 SKHY, 2026-07-10 상장, OTC상 대체 코드 HXSCL 병존)을 가리킴. 원주는 KRX 000660(KOSPI). 유동성·재무·컨센서스는 원주 000660.KS 기준으로 수집(ADR보다 데이터 풍부·정확), 필요시 ADR 고유 정보(환율, 희석)는 별도 표기. 통화: 원화(KRW), 별도 언급 없는 한 전 수치 KRW.

## 1. 기업 개요
- **사업 모델**: 메모리반도체(DRAM·NAND·SSD·MCP) 설계·제조·판매. HBM(고대역폭메모리)이 AI 서버향 핵심 성장동력. 파운드리(비메모리) 소규모 겸업.
- **주요 세그먼트**: DRAM(서버·모바일·PC·그래픽), NAND/SSD, HBM(HBM3E→HBM4 전환 중)
- **경쟁사**: 삼성전자(005930.KS), Micron(MU), (HBM 한정) 삼성전자·마이크론이 직접 경쟁
- 본사: 경기 이천. 직원 약 47,639명(자산프로파일 기준)

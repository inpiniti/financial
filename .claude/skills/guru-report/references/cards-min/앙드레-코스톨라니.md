# 앙드레 코스톨라니

## 투자 철학 (판정에 쓰이는 것만)
- 주가 = 유동성 × 심리. 유동성 방향(금리 방향이 절대 수준보다 중요)과 시장 심리(낙관/비관)로 국면을 판정한다.
- 달걀 모형 6국면: **A1(조정, 상승 초입) → A2(동행, 상승 지속) → A3(과열, 상승 말기) → B1(조정, 하락 초입) → B2(동행, 하락 지속) → B3(과매도, 하락 말기)**. B3에서 매수, A3에서 매도.
- 소신파(여유자금+독립판단+인내심) vs 부화뇌동파(빚투+군중추종+조바심). 돈은 부화뇌동파→소신파로 이동.
- 뉴스 자체가 아니라 뉴스에 대한 시장 반응을 본다.

## 체크리스트
- **유동성×심리 4분면**: 풍부+비관=바닥 회복(최고의 매수 기회) / 부족+낙관=고점 근처(위험) / 풍부+낙관=강한 상승 / 부족+비관=강한 하락
- **국면 판별**: 거래량, 미디어 관심, 초보 투자자 유입 정도로 A1~B3 중 위치 판정
- **A3(과열) 신호**: 모두가 매수 중, 가격이 펀더멘털 크게 초과, 빚내서 뛰어드는 초보 급증
- **B3(과매도) 신호**: 공포 극에 달함, 주가가 펀더멘털 이하, 거래량마저 감소
- **뉴스 반응 테스트**: 악재에도 안 떨어지면 바닥 근처 / 호재에도 안 오르면 고점 근처
- **금리 방향**: 하락 전환=긍정적, 상승 전환=부정적 (절대 수준 아닌 방향)
- **개별 기업 (시장 판단 후 부차적 확인)**: 독점적 지위·경쟁력, 낮은 부채, 유능하고 정직한 경영진
- **자기 점검**: 독립 판단인가 vs 뉴스·소문 추종인가 / 여유자금인가 vs 빌린 돈인가

## 매수·매도 기준
- **매수**: B3 국면(공포 극대, 주가<펀더멘털, 거래량 마름) / 유동성 풍부+심리 비관 / 금리 하락 전환 / 악재에도 하락 멈춤
- **매도**: A3 국면(빚투 급증, "더 오른다" 확신 만연) / 유동성 감소+심리 낙관 / 금리 상승 전환 / 호재에도 상승 멈춤
- **보유/관망**: A1~A2(상승 초·중반) 또는 B1~B2(하락 초·중반)로 국면이 뚜렷한 극단(A3/B3)에 도달하지 않은 경우, 인내심을 갖고 유지

# 마이클 버리 — 빅 숏

## 투자 철학 (판정에 쓰이는 것만)
- 원자료(공시·계약·약관) 직접 검증이 유일한 근거. 애널리스트 요약·신용등급 의존은 감점.
- 컨센서스는 검증 대상. 모두가 같은 걸 믿을 때가 가장 위험.
- 인센티브 추적: 위험을 만든 주체가 그 위험을 떠안는가, 떠넘기는가.
- 복잡성은 위험을 감추는 신호. 이해 못 하면 투자하지 않는다.
- 비대칭 베팅만 정당화된다: 손실 한정, 보상 개방형.
- 실행 수단이 없으면 만들어서라도 진입.
- 옳음과 버티기는 별개: 전제가 안 깨졌으면 가격 하락은 매도 사유 아님.
- 권위(등급·평판)는 분석을 대체 못 함.

## 체크리스트
- **원문 검증**: 공시·계약 조항을 직접 확인했는가, 아니면 요약/등급에 의존했는가
- **핵심 가정**: 가치가 의존하는 단일 가정은 무엇이며, 무너지면 어떻게 되는가
- **인센티브 구조**: 경영진·판매자·평가자의 보상 구조가 위험을 숨기는가
- **복잡성 심사**: 수익 구조를 한 문단으로 설명 가능한가 (불가하면 배제)
- **위험/보상 비대칭**: 최대 손실 한도 vs 실현 시 보상 배수 — 손실 한정·보상 개방형이 아니면 포지션 확대 불가
- **기초 실물 데이터**: 연체율·상환 실패 등 실물 지표가 가격/등급과 괴리되는가
- **컨센서스와의 거리**: 시장 통념과 결론이 얼마나 다르며 근거를 문서화했는가
- **버티기 가능성**: 실현까지 수년 걸려도 견딜 자금·심리 여력이 있는가, 유지비용(보험료 등)이 자본을 얼마나 갉아먹는가

## 매수·매도 기준
- **매수**: 원자료 분석이 컨센서스와 정면 배치 + 근거 문서화 / 위험·보상 비대칭 큼(손실은 프리미엄 수준, 보상 수배~수십 배) / 핵심 가정 붕괴가 방향상 필연(시점 불확실해도 무방) / 필요시 실행 수단 자체 설계
- **매도**: 예견 시나리오가 실현되어 비대칭 소진 / 원자료 재검증 결과 애초 전제가 틀렸음이 확인됨(이때만 손절) / 군중이 내 결론에 동의하기 시작하면 기회 대부분 소멸
- **보유/관망**: 손실이 기록돼도 분석 전제가 유효하면 유지, 가격 하락 자체는 매도 사유 아님

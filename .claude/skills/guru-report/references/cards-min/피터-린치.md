# 피터 린치

## 투자 철학
- 6가지 유형별로 기대수익·위험·매도 기준이 다름 (유형 분류가 판정 출발점)
- 2분 독백: 매수 이유를 2분 내 설명 못 하면 보류
- 주가가 아니라 스토리를 따라간다 — 스토리 유효=하락도 매수기회, 훼손=매도신호
- 시장 타이밍/거시 예측은 판정 근거로 안 씀

## 체크리스트

### 1단계 — 유형 분류
- **저성장주**: 경제성장률 이하, 고배당 → 배당 외 기대 낮음
- **대형우량주**: 연10~12% 안정성장 → 30~50%↑ 시 교체검토
- **고성장주**: 연20~25%+ 이익성장 → 스토리 유효한 한 장기보유
- **경기순환주**: 실적 급변동(자동차·항공·철강·화학) → 업황 타이밍 핵심
- **턴어라운드주**: 파산위기·대규모적자→회복중 → 회복가능성이 관건
- **자산주**: 부동산·특허·현금·자회사지분 저평가 → 적정가 도달 시 매도

### 2단계 — 정량 지표
- **PEG(PER÷이익성장률)**: <1 저평가 가능, ≥2 과대평가. 고성장주에 유용, 저성장·경기순환주엔 부적합
- **부채비율**: 과다=침체기 생존 위협. 턴어라운드주는 현금·상환능력이 핵심
- **현금흐름**: 순이익보다 FCF 중시. FCF 꾸준히 플러스=자체성장 가능
- **재고**: 재고 증가율>매출 증가율 = 위험신호
- **내부자매수**: 경영진 자사주 매수 = 긍정신호

### 3단계 — 2분 독백
- 6가지 유형 중 어디인가 / 매수 근거는 구체적인가 / 스토리 실현조건과 훼손위험은?

## 매수·매도 기준
- **매수**: 타이밍 무관, 펀더멘털 근거로 적정가 매수. 폭락=매수기회. 물타기는 스토리·펀더멘털 건재할 때만
- **매도**: 저성장주(펀더멘털 악화·배당삭감위험) / 대형우량주(30~50%↑ 차익실현, PER 이탈) / 고성장주(성장둔화·임원이탈·실적부진) / 경기순환주(재고누적·원자재↓·경쟁사증설=정점징후) / 턴어라운드주(회복성공 시 유형 재분류) / 자산주(자산 인정받거나 적정가 도달)
- **보유/관망**: 스토리 유효+독백 명확+정량지표 경고없음=보유. 독백 불분명·유형불명=관망
